# История изменений

## 0.5.1 — 2026-10-26

- Исправлен перенос строки по Shift+Enter в терминалах с расширенным протоколом клавиатуры, включая Ghostty.
- Режим клавиатуры восстанавливается после форм подключения и при выходе; Alt+Enter и Ctrl+J сохранены.
- Исправлено завершение приложения при изменении размера окна после отмены формы подключения.

## 0.5.0 — 2026-10-26

- Полноэкранный терминал с Markdown, блоками кода, закреплённым футером, прокруткой и копированием мышью.
- История ввода между запусками и восстановление конкретной сессии через `--resume ID`.
- Автоматическое сокращение контекста, включая заполненную историю после восстановления.
- Команды `!` для явного запуска shell и `/export` для сохранения диалога в Markdown.
- Скриншоты PNG/JPEG/TIFF с локальными копиями для восстановления сессии.
- Превышение лимита вложений отклоняется до сохранения и не мешает восстановить сессию.
- Сохранённый режим `full-access` на проект и работа с явно разрешёнными внешними каталогами.
- Исправлены совместимость схем инструментов GigaChat и повторяющиеся ошибки файловых правок.
- Краткое руководство, GIF с GigaChat Ultra и готовые архивы для macOS, Linux и Windows.

## 0.4.4 — 2026-10-24

- Первая версия агента на Rust с Yandex AI Studio, GigaChat, OpenRouter и OpenAI-совместимым API.
- Работа с файлами, shell, разрешениями, diff и undo.
- Субагенты, выбор модели и effort, сохранение сессий и запуск отдельных задач через `exec`.
