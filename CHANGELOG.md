# История изменений

## 0.7.0 — 2026-10-31

- Провайдер `local` для запущенных вами серверов Ollama, llama.cpp, MLX и LM Studio на 127.0.0.1: несколько именованных профилей, поиск серверов на стандартных портах, `/provider` → `local` и команды `rcode local discover|list|add|use|key|remove`, флаг `--profile`.
- Ключ локального сервера необязателен, вводится только через stdin или скрытый ввод и отправляется только на адрес своего профиля. Ключи облачных провайдеров из окружения на локальный сервер не уходят.
- Одна генерация на локальный сервер, включая субагентов. Бюджет контекста local в оценочных токенах с учётом фактического контекста llama.cpp и Ollama; футер показывает оценку в токенах.
- Рассуждения локальных моделей не показываются и не сохраняются в истории.
- Сокращённые receipts local сохраняют статус и ключевые поля результата: `exit_code`, `error`, `path` и другие; denied/interrupted/unknown не превращаются в успех. Идентичные повторные read-only наблюдения получают понятное сообщение и останавливают ход вместо бесконечного цикла чтений.
- JSONL: новое событие `warning`; `context_compacted` для local содержит `unit: "estimated_tokens"` и поля `before`, `after`, `saved`. Формат событий облачных провайдеров не изменился.
- Конфигурация с активным `local` и сессии local не читаются версиями 0.6.2 и старше.

## 0.6.2 — 2026-10-28

- На вопрос о балансе агент вызывает `get_provider_balance` и получает свежий остаток текущего провайдера: деньги и лимит ключа OpenRouter либо пакет выбранной модели GigaChat.
- `/balance` больше не предлагается выполнять через shell. Исправлены объяснения недоступности данных; отсутствие данных не считается нулевым балансом.
- Фоновый баланс остаётся локальным. Результат явного вызова инструмента сохраняется в диалоге; ключи и данные других провайдеров модели не выдаются.

## 0.6.1 — 2026-10-27

- Последняя выбранная модель каждого провайдера стоит первой и сразу выделена в меню, включая мастер подключения; Enter сохраняет её и effort.
- В `/provider` доступны балансы OpenRouter в долларах и GigaChat в токенах сохранённой модели. Фоновая загрузка сохраняет поиск и выбранный пункт; выход из меню отменяет запросы.

## 0.6.0 — 2026-10-27

- Баланс активного провайдера в футере с фоновым обновлением раз в минуту.
- `/balance` и `rcode balance`: деньги на счёте OpenRouter, отдельные лимиты ключа и остатки пакетов токенов GigaChat; поддержан JSONL.
- При сбое API последнее значение помечается устаревшим; смена провайдера отменяет предыдущий запрос баланса.
- Баланс остаётся в интерфейсе и не передаётся модели. Для Yandex Billing и произвольного API показаны ограничения доступа.

## 0.5.1 — 2026-10-26

- Исправлен перенос строки по Shift+Enter в терминалах с расширенным протоколом клавиатуры, включая Ghostty.
- Режим клавиатуры восстанавливается после форм подключения и при выходе; Alt+Enter и Ctrl+J сохранены.
- Исправлено завершение приложения при изменении размера окна после отмены формы подключения.

## 0.5.0 — 2026-10-26

- Полноэкранный терминал с Markdown, блоками кода, закреплённым футером, прокруткой и копированием мышью.
- История ввода между запусками и восстановление конкретной сессии через `--resume ID`.
- Автоматическое сокращение контекста, включая заполненную историю после восстановления.
- Команды `!` для явного запуска shell и `/export` для сохранения диалога в Markdown.
- Скриншоты PNG/JPEG/TIFF с локальными копиями для восстановления сессии.
- Превышение лимита вложений отклоняется до сохранения и не мешает восстановить сессию.
- Сохранённый режим `full-access` на проект и работа с явно разрешёнными внешними каталогами.
- Исправлены совместимость схем инструментов GigaChat и повторяющиеся ошибки файловых правок.
- Краткое руководство, GIF с GigaChat Ultra и готовые архивы для macOS, Linux и Windows.

## 0.4.4 — 2026-10-24

- Первая версия агента на Rust с Yandex AI Studio, GigaChat, OpenRouter и OpenAI-совместимым API.
- Работа с файлами, shell, разрешениями, diff и undo.
- Субагенты, выбор модели и effort, сохранение сессий и запуск отдельных задач через `exec`.
