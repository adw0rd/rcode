# Участие в разработке

Понадобится Rust 1.88+. Клонируйте репозиторий и установите локальную сборку:

```sh
git clone https://github.com/adw0rd/rcode.git
cd rcode
cargo install --path . --locked
```

Перед отправкой изменений выполните:

```sh
cargo fmt --all --check
cargo clippy --all-targets --locked -- -D warnings
cargo test --all-targets --locked
cargo build --release --locked
```

Обычные проверки не требуют API-ключей. Терминальные проверки на Linux/macOS используют Python 3 со стандартными модулями PTY, TLS-проверки — OpenSSL. Изменения адаптеров проверяйте локальными HTTP/SSE/TLS-серверами; при проверке живого API явно указывайте модель и фактический результат.

В issue с ошибкой укажите `rcode --version`, ОС, провайдера, модель и шаги воспроизведения. Удалите ключи, персональные данные и чувствительные фрагменты проекта из логов и скриншотов.

В pull request опишите, что изменилось и как это проверено. Сохраняйте русский язык интерфейса и документации, общий формат сессий между провайдерами и поддержку `--plain`/JSONL. Подробные правила находятся в [AGENTS.md](AGENTS.md).
