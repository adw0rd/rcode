Реализуйте восстановление сохранённого состояния счётчика. Модуль state_store должен читать JSON из указанного пути; при отсутствующем файле или некорректном JSON возвращать начальное состояние {"count": 0}. При корректном объекте с целым count вернуть это значение. CLI принимает путь первым аргументом и печатает JSON-состояние.
