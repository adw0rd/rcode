# Анализ показаний

Нужно реализовать модуль `readings.py`.

Функция `running_totals(values)` принимает список целых чисел и возвращает новый список накопительных сумм. Например, для значений `[2, -1, 4]` результат имеет ту же длину, а каждый элемент равен сумме префикса до этой позиции. Входной список изменять нельзя. Для пустого списка результат пустой.
